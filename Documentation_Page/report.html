ViewX / Report

Report

Clase para generar documentos PDF profesionales usando LaTeX. Soporta secciones, tablas, imagenes, codigo, graficos TikZ/PGFPlots y cajas destacadas.

Descripcion general

Report genera documentos PDF de alta calidad (LaTeX por debajo, sin necesidad de conocer LaTeX). El flujo de trabajo es simple:

  1. Crear una instancia de Report con titulo y autor
  2. Agregar contenido con with r.section(...), text(), bullets(), add_table()...
  3. Llamar a save("archivo.pdf") para compilar el PDF

Requisitos

⚠ Requisito importante

Report requiere una instalacion de LaTeX (pdflatex) en tu sistema. En Ubuntu/Debian: sudo apt install texlive-full. En macOS: brew install mactex.

Inicio rapido

Python 
from viewx import Report

# Crear reporte
report = Report(
    title="Informe Trimestral",
    author="Emmanuel Ascendra",
    outdir="output"
)

# Agregar contenido
report.text("Este es el informe del Q4 2024.", bold=True)
with report.section("Resultados"):
    report.add_table(
        headers=["Producto", "Ventas", "Crecimiento"],
        rows=[
            ["Producto A", "1,200", "+15%"],
            ["Producto B", "890", "+8%"]
        ],
        caption="Ventas por producto"
    )

# Compilar PDF
report.save("informe_q4.pdf")

Constructor

Report(title, author, outdir, two_column, images_dir)
Inicializa un nuevo documento con los paquetes necesarios preconfigurados (geometry, float, graphicx, tikz, pgfplots, tcolorbox, listings).
title str, default="Reporte" - Titulo del documento
author str, default="Autor" - Autor del documento
outdir str, default="output" - Directorio de salida
two_column bool, default=False - Si True, usa formato de dos columnas
images_dir str, default="images" - Subdirectorio para imagenes

text()

text(text, bold=False)
Agrega texto plano al documento. Opcionalmente en negrita. (add_text() es equivalente.)
text str - Texto a agregar
bold bool - Si True, aplica negrita

section() / subsection()

with report.section(title): ...
Abre una seccion como context manager: todo lo agregado dentro del bloque with queda anidado en ella. Sin PyLaTeX expuesto.
with report.subsection(title): ...
Igual, para subsecciones (anidable dentro de una seccion).

add_image()

add_image(filename, caption, width, placement)
Inserta una imagen en el documento. Si la imagen no esta en el directorio de imagenes, se copia automaticamente.
filename str - Nombre del archivo de imagen
caption str, optional - Leyenda de la figura
width float, default=0.6 - Ancho como fraccion del ancho de linea (0-1)
placement str, default="H" - Posicionamiento LaTeX (H, h, t, b)

add_table()

add_table(headers, rows, caption)
Crea una tabla con encabezados y filas de datos.
headers list[str] - Lista de encabezados de columna
rows list[list] - Lista de filas (cada fila es una lista)
caption str - Titulo de la tabla

add_code()

add_code(code, language="python")
Inserta un bloque de codigo con syntax highlighting usando el paquete listings.
code str - Codigo fuente
language str - Lenguaje para syntax highlighting

bullets() / numbered()

bullets(items)
Crea una lista con vinetas. (add_itemize() es equivalente.)
numbered(items)
Crea una lista numerada. (add_enumerate() es equivalente.)

add_box()

add_box(title, content, color="#DBEAFE")
Crea una caja destacada. Ideal para notas, advertencias o contenido importante.
title str - Titulo de la caja
content str - Contenido de la caja
color str - Color de fondo: hex CSS ("#DBEAFE"), nombre basico ("green") o spec LaTeX

add_line_plot()

add_line_plot(x, y, caption)
Genera un grafico 2D estatico renderizado nativamente en el PDF. Ideal para graficos simples sin dependencias externas.
x list - Valores del eje X
y list - Valores del eje Y
caption str - Leyenda del grafico
Python 
x = [1, 2, 3, 4, 5]
y = [2.3, 4.1, 3.8, 5.2, 4.9]
report.add_line_plot(x, y, caption="Tendencia mensual")

add_multiplot()

add_multiplot(plots, caption)
Genera un grafico con multiples series de datos superpuestas.
plots list[tuple] - Lista de tuplas (x, y) para cada serie
caption str - Leyenda del grafico

save() / show()

save(path="reporte.pdf") → str
Compila el documento y genera el PDF. Si path no incluye carpeta, se guarda en el outdir del constructor. show() compila y abre el PDF.
path str - Nombre o ruta del PDF
Python 
# Genera output/mi_reporte.pdf
report.save("mi_reporte.pdf")

Report.auto()

Report.auto(df, title, author, outdir, include_plots=True) → Report
Genera un reporte automatico con resumen ejecutivo, advertencias, fortalezas, perfiles de columnas, correlaciones, graficos y muestra de datos. Devuelve el Report; compilalo con .save(path). Requiere pdflatex.
Python 
from viewx import Report
from viewx.datasets import load_iris

Report.auto(load_iris(), title="Iris Quality").save("iris_quality.pdf")

begin_multicols() / new_page()

begin_multicols(n=2) / end_multicols()
Layout en multiples columnas dentro del documento.
new_page()
Inserta un salto de pagina.
