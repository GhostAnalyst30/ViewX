ViewX / DataMatrix

DataMatrix

Clase para analisis exploratorio automatico de DataFrames. Genera reportes HTML interactivos con estadisticas, visualizaciones y alertas de calidad de datos.

Descripcion general

DataMatrix toma un DataFrame de pandas y genera automaticamente un reporte HTML completo con:

  • Resumen del dataset (filas, columnas, nulos, duplicados)
  • Analisis por variable (tipo, estadisticas, distribucion)
  • Alertas automaticas de calidad de datos
  • Visualizaciones interactivas con Plotly
  • Analisis bibliometrico opcional (si detecta columnas relevantes)

Instalacion

pip install viewx

Inicio rapido

Python 
from viewx import DataMatrix
from viewx.datasets import load_iris

# Cargar datos
df = load_iris()

# Crear instancia y generar reporte
dm = DataMatrix(df)
dm.clean_data(drop_duplicates=True, fill_na=True)
dm.generate_report("mi_reporte.html", title="Analisis Iris")

Constructor

DataMatrix(df: pd.DataFrame)
Inicializa una instancia de DataMatrix con un DataFrame de pandas. Crea copias internas del DataFrame original y prepara los contenedores para estadisticas y alertas.
df pd.DataFrame - DataFrame a analizar
ⓘ Nota

DataMatrix mantiene una copia del DataFrame original (self.original_df) y una copia de trabajo (self.df) para preservar los datos originales durante la limpieza.

clean_data()

clean_data(drop_duplicates=True, fill_na=False)
Limpia el DataFrame eliminando duplicados y/o imputando valores faltantes. Los valores numericos se imputan con la mediana, los categoricos con la moda.
drop_duplicates bool, default=True - Si True, elimina filas duplicadas
fill_na bool, default=False - Si True, imputa valores faltantes
Python 
dm = DataMatrix(df)

# Solo eliminar duplicados
dm.clean_data(drop_duplicates=True, fill_na=False)

# Eliminar duplicados e imputar nulos
dm.clean_data(drop_duplicates=True, fill_na=True)

generate_report()

generate_report(output_path="datamatrix_report.html", title="Viewx DataMatrix Report")
Genera el reporte HTML completo con todas las secciones: resumen general, analisis de variables, bibliometria (si aplica) y muestra de datos. Abre automaticamente el archivo en el navegador.
output_path str - Ruta del archivo HTML de salida
title str - Titulo del reporte
Python 
dm = DataMatrix(df)
path = dm.generate_report(
    output_path="analisis_ventas.html",
    title="Reporte de Ventas Q4 2024"
)
print(f"Reporte generado: {path}")

_analyze_columns()

_analyze_columns()
Metodo interno que analiza cada columna del DataFrame. Detecta el tipo de dato, calcula estadisticas descriptivas y genera alertas automaticas para problemas de calidad de datos.

Para columnas numericas calcula: mean, std, min, max, median. Genera alertas si:

  • Una columna tiene mas del 50% de valores faltantes
  • Una columna tiene un solo valor constante

_get_column_type()

_get_column_type(series) → str
Determina el tipo de una columna. Retorna: "numeric", "datetime", "boolean" o "categorical".

_assemble_html()

_assemble_html(title, bib_results) → str
Ensambla el HTML final del reporte. Utiliza Bootstrap 5 para el layout y Plotly para los graficos interactivos. Incluye tabs para navegar entre secciones.
